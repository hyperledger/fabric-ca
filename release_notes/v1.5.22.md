v1.5.22 Release Notes - July 29, 2026
========================================

v1.5.22 updates dependencies to address the following security
vulnerabilities:

- CVE-2026-56852

This release also delivers the following changes:

- Fix CLI client command detection when flags precede subcommand.
- Add s390x as a target platform for Docker images and binaries.

Dependencies
------------

Fabric CA v1.5.22 has been tested with the following dependencies:
- Go 1.26.4
- Ubuntu 22.04 (for Docker images)
- Databases
    - PostgreSQL 17
    - MariaDB 11
